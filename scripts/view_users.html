How this works right now: this page reads a static file, users_export.json, in the same folder. Re-run python scripts/export_users.py from backend/ whenever you want fresh data, then click Refresh above.

Wiring it to your live backend later: once your teammate's FastAPI app is running, ask them to add a protected GET /admin/users endpoint that returns this same JSON shape (id, username, email, created_at, total_uploads, total_downloads). Then just change the fetch('users_export.json') line near the bottom of this file to fetch('http://localhost:8000/admin/users', { headers: { Authorization: 'Bearer ' + token } }) and this page will show live data instead of a snapshot.
